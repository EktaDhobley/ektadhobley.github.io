#### Multi-Database Query Platform
Rutgers University · MS Computer Science

Built a web application that unified querying across four database systems: MySQL, MSSQL, RedShift, and MongoDB. Designed the full data layer including ER diagrams, normalized schemas, and ETL pipelines. Features included live query execution with elapsed time tracking, CSV export, and inline ER diagram rendering to reduce the friction of writing complex queries across different dialects.

**Tech:** Python · MySQL · MSSQL · RedShift · MongoDB · ETL

#### CitiBike Trip Duration Prediction
Rutgers University · MS Computer Science

Analyzed CitiBike ridership data alongside daily NYC weather records to study how weather conditions affect shared bike usage. Built a predictive model to estimate trip duration as a proxy for resource allocation across docking stations. Compared Linear Regression, Stochastic Gradient Boosting, XGBoost, and Random Forests. Random Forests and SGB produced the strongest results with RMSE values of 7.86 and 7.95 minutes respectively.

**Tech:** Python · Scikit-learn · Pandas · Random Forests · XGBoost

#### Customer Behavior Analysis
Rutgers University · MS Computer Science

Implemented and compared clustering algorithms — KMeans, OPTICS, and DBSCAN — to identify shopping activity patterns from a retail dataset. Analyzed correlating customer attributes and visualized cluster formations across varying data densities. OPTICS outperformed the others on non-uniform datasets due to its adaptive density estimation.

**Tech:** Python · Scikit-learn · Matplotlib · Pandas
